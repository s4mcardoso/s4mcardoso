# Opa, eu sou o Samuel 👋

Trabalho com TI em Sorocaba/SP. Hoje atuo em uma consultoria fazendo migrações tenant-to-tenant no Microsoft 365 e curso Análise e Desenvolvimento de Sistemas na FACENS.

Gosto de entender como as coisas funcionam por baixo, então costumo montar laboratórios para estudar cada parte do que faço no trabalho e documento tudo aqui.

## No que estou trabalhando

- Migração tenant-to-tenant no Microsoft 365
- Identidade híbrida com Active Directory, Microsoft Entra ID e Entra Connect Sync
- Automação com PowerShell
- Estudos de desenvolvimento com Java, Python e Go

## Projeto em destaque

**[lab-t2t-migration](https://github.com/s4mcardoso/lab-t2t-migration)**
Laboratório de estudo com duas florestas Active Directory sincronizadas para dois tenants Microsoft 365, preparando uma migração com o Quest On Demand Migration. Inclui arquitetura, passo a passo, scripts de validação e os problemas que resolvi no caminho (DNS, Kerberos e regras de sincronização).
